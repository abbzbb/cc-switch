# 4.8 Web Search / Vision Sidecar

Sidecar 让**已登录**的 Claude Pro/Max 或 ChatGPT Official 替非官方模型做两件事：

1. **Web Search**：非官方、非 Anthropic OAuth 卡上的 hosted `web_search` 会改成函数调用，由 sidecar 账号执行后再把结果交回原模型。
2. **Vision**：纯文本模型收到图片时，先由 sidecar 描述图片，再把描述转发给原模型。

未登录对应账号时，这两步都保持原样（不改写、不拦截）。官方 ChatGPT 卡和 Anthropic OAuth 卡**不会**拦截它们自己的 hosted 搜索。

> 不需要单独安装或启动 OpenCodex。Sidecar 跑在本机代理里。Responses、Claude `/v1/messages`、Codex `/v1/chat/completions` 都会走同一套循环。

## 使用前准备

1. 在 **设置 → OAuth 认证中心** 登录至少一个后端：
   - **Claude Pro/Max**：浏览器登录（本机 `http://localhost:54545/callback`）或从 Claude CLI 导入
   - **ChatGPT Official**：ChatGPT（Codex OAuth）设备码登录
2. 启动代理，并接管会发 hosted 搜索或带图请求的应用。
3. 打开 **Proxy** 面板，找到 **Web Search / Vision Sidecar**。

没有可用后端时，开关可以开着，请求也不会被改写。

## 面板里怎么设

Web Search 和 Vision 各自一组开关，改完即时保存。

| 项 | 作用 |
|----|------|
| Web Search / Vision 开关 | 关闭后该能力完全不介入 |
| 搜索后端 / 识图后端 | `自动`、`Claude Pro/Max`、`ChatGPT Official` |
| 搜索模型 / 识图模型 | 可选。留空则用该后端默认模型 |
| 每轮最多搜索 | 单轮对话里 sidecar 最多执行几次搜索 |
| 每轮最多描述 | 单轮里最多描述几张图 |
| 搜索超时 / 识图超时 | 毫秒。超时后该次 sidecar 调用失败，原请求按未改写或已有结果继续 |

**自动**：优先用当前已登录且可用的后端。只登录了一边时，自动就会用那一边。

## 什么请求会被改写

| 场景 | 是否改写 |
|------|----------|
| 中转卡 / API Key 卡带 hosted `web_search` | 会，改成函数调用交给 sidecar |
| 官方 ChatGPT 卡自己的 hosted 搜索 | 不拦截 |
| Claude Pro/Max OAuth 卡自己的 hosted 搜索 | 不拦截 |
| 纯文本模型的消息里带图片 | 会先描述再转发 |
| 本身就能看图的模型 | 不强制走 sidecar 识图 |
| 认证中心两边都没登录 | 不改写 |

## 推荐用法

**中转模型要联网搜，但该供应商没有 hosted search**

1. 登录 Claude Pro/Max 或 ChatGPT Official。
2. 打开 Web Search，后端选自动或指定一侧。
3. 继续用中转卡的 `{slug}/{model}` 或当前供应商发请求。模型一旦请求 `web_search`，代理会改到 sidecar。

**文本模型要看截图**

1. 打开 Vision，选好后端。
2. 把图片发给该文本模型。sidecar 先写出描述，再交给原模型作答。

**只要搜索、不要识图**

关掉 Vision，只留 Web Search。

## 注意事项

- Sidecar 消耗的是 **Claude Pro/Max 或 ChatGPT 订阅额度**，不是中转卡余额。认证中心和对应官方卡底部可以看到用量。
- 官方 ChatGPT sidecar 请求会带上账号与窗口头（如 `chatgpt-account-id`、`session_id`），以便 Codex 后端识别会话。无需手动配置。
- 取消 Claude 浏览器登录会中止本机 PKCE 回调；不要在登录过程中关掉占用 `54545` 的其他程序。
- 空的 Claude 官方种子卡不能当 sidecar 后端。必须是认证中心里已登录、或已绑定 token 的 Claude Pro/Max。
