# 4.8 Web Search / Vision Sidecar

Sidecar は**ログイン済み**の Claude Pro/Max または ChatGPT Official に、非公式モデル向けの 2 つの仕事を任せます。

1. **Web Search**：非公式・非 Anthropic OAuth カード上の hosted `web_search` を関数呼び出しに書き換え、sidecar アカウントが実行して元モデルへ返します。
2. **Vision**：テキストのみモデルが画像を受け取ったとき、先に sidecar が説明し、その説明を転送します。

選んだバックエンドに誰もログインしていなければ、どちらも何もしません。公式 ChatGPT カードと Anthropic OAuth カードは、自分自身の hosted 検索を横取りしません。

> OpenCodex を別途入れる必要はありません。Sidecar はローカルプロキシ内で動きます。Responses、Claude `/v1/messages`、Codex `/v1/chat/completions` は同じループです。

## 準備

1. **設定 → OAuth 認証センター**で少なくとも一方にログインする。
   - **Claude Pro/Max**：ブラウザ（`http://localhost:54545/callback`）または Claude CLI から取り込み
   - **ChatGPT Official**：ChatGPT（Codex OAuth）のデバイスコード
2. プロキシを起動し、hosted 検索や画像を送るアプリを接管する。
3. **Proxy** パネルの **Web Search / Vision Sidecar** を開く。

Web Search と Vision は**既定でオフ**です。バックエンド未ログインのままスイッチをオンにしても、リクエストは書き換えられません。有効化後、プロキシが Official / Claude の枠を消費するには、テイクオーバー時に書き込まれたインバウンド能力ヘッダーも必要です。

## パネル

Web Search と Vision は別スイッチです。変更はすぐ保存されます。

| 項目 | 意味 |
|------|------|
| Web Search / Vision | オフでその能力は介入しない |
| 検索 / 識図バックエンド | `自動`、`Claude Pro/Max`、`ChatGPT Official` |
| 検索 / 識図モデル | 任意。空ならバックエンド既定 |
| 1 ターンあたり最大検索 | sidecar 検索の上限 |
| 1 ターンあたり最大説明 | 画像説明の上限 |
| 検索 / 識図タイムアウト | ミリ秒。タイムアウトした sidecar 呼び出しは失敗し、元リクエストは続行 |

**自動**はログイン済みで使えるバックエンドを使います。一方だけログインしていればそちらです。

## 何が書き換わるか

| 状況 | 書き換え |
|------|----------|
| 中継 / API Key カードの hosted `web_search` | する（関数呼び出しへ） |
| 公式 ChatGPT カード自身の hosted 検索 | しない |
| Claude Pro/Max OAuth カード自身の hosted 検索 | しない |
| テキストのみモデルへの画像 | する（説明してから転送） |
| もともと画像を見られるモデル | Vision sidecar は強制しない |
| どちらも未ログイン | しない |

## 使い方

中継モデルにネット検索が必要で、ベンダーに hosted search がないとき：Claude Pro/Max または ChatGPT Official にログインし、Web Search をオンにして、これまでどおり中継カードへ送ります。モデルが `web_search` を求めるとプロキシが sidecar に渡します。

テキストモデルにスクリーンショットを読ませるときは Vision をオンにします。sidecar が説明を書き、元モデルが答えます。

検索だけ欲しいときは Vision をオフにします。

## 注意

- Sidecar の消費は **Claude Pro/Max または ChatGPT のサブスク**であり、中継カードの残高ではありません。
- 公式 ChatGPT sidecar はアカウント/ウィンドウ用ヘッダを付けます。手動設定は不要です。
- Claude のブラウザログインをキャンセルするとローカル PKCE コールバックも中止されます。ログイン中はポート `54545` を塞がないでください。
- 空の公式 Claude シードカードは sidecar バックエンドになりません。
